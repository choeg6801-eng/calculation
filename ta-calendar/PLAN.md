# 내 서비스 한 장 기획

## 서비스 이름
선적일 역산 캘린더

- "T&A"는 의류업 용어라서, 4개 산업 모두에 맞게 이름에서 뺐다.

## 한 줄 설명
선적일(ETD)을 넣으면 샘플·자재·생산·검사 마감일을 거꾸로 계산해 주는 화면. PO 접수일을 넣으면 가능한 가장 빠른 선적일도 계산한다.

## 사용자
수출 기업의 해외영업 담당자 (업종 무관, 공장·바이어와 일정을 맞추는 사람). 특정 업종 전용이 아님.

## 만드는 목적 / 대상 업종
취업 준비용 포트폴리오. 지원하려는 4개 업종(전기·전자, 의료기기, 제약, 방위)에서 쓸 수 있게 만든다.

- 업종 예시값 선택: 일반 제조 / 전기·전자 / 의료기기 / 제약 / 방위. 고르면 단계 이름(한·영)과 예시 기간이 바뀐다.
- 인허가·인증·수출허가 단계는 "기간 변동 큼"으로 표시하고, 전체 여유가 14일 미만이면 주의 문구를 보여 준다.
- 지원 직무는 해외영업. 내부 공정은 간단히 두고, 영업이 챙기는 허가·인증·검사·출하 단계를 구체적으로 둔다.
- 인허가·인증·등록 단계는 "신규 제품만" 필요할 수 있어 삭제 안내를 둔다. 방위는 수출 예비 승인(계약 전)과 국회 동의 안내를 둔다.
- 업종별 단계와 숫자는 모두 예시값이며, 실제 규정·기간은 공식 절차로 확인해야 한다고 화면에 안내한다.
- 지원 업종 용어는 직접 검수해서 고친다. (틀린 용어 방지)

## 해결하는 불편
선적일에 맞춰 단계별 마감일을 매번 손으로 계산하고, 일정이 모자란 걸 늦게 알아차림

## 첫 화면에서 사용자가 해야 할 단 하나의 행동
**선적일 넣고 일정 받기**

- 첫 화면에서는 선적일 칸을 가장 눈에 띄게 둔다.
- 오더명·바이어·업종 예시값·리드타임 편집은 보조 기능으로 둔다.

## 행동 뒤에 사용자가 얻는 것
단계별 마감일 표, 타임라인 막대, 일정 부족 경고, 복사할 수 있는 일정 텍스트(한국어·영어)

## 성공 기준
처음 방문한 사람이 1분 안에 일정 텍스트를 복사한다.

## 유지할 기능 (다음 단계에서도 그대로 유지)
지금 있는 계산 기능은 다음 단계에서도 **그대로 유지**한다. 동작을 바꾸지 않는다.

- 단계별 리드타임 편집
- 주말 제외(영업일) 계산 (입력한 휴일도 함께 제외 가능)
- 일정 부족 경고
- 타임라인 막대
- 한국어·영어 일정 텍스트 복사

## 추가한 기능 (기존 계산은 그대로 두고 더함)
- 순방향 계산: PO 접수일 → 가능한 가장 빠른 선적일. 바이어 요청 선적일을 넣으면 맞출 수 있는지, 첫 단계 마감 한도를 알려 준다.
- 휴일 직접 입력: 영업일 계산에서 제외할 날짜를 사용자가 입력한다. 공휴일 목록은 나라·해마다 달라 자동으로 넣지 않는다.
- 저장한 오더: 여러 오더를 이 브라우저에 저장·불러오기·삭제. 선적일이 빠른 순으로 보여 준다.
- 캘린더 파일(.ics) 내보내기: 각 단계와 선적일을 종일 일정으로 만든다.

## 지금 안 하는 것 / 다음 단계 후보
- 다음 단계 후보: 나라별 공휴일 자동 반영 (공식 자료로 검증된 목록이 있을 때)
