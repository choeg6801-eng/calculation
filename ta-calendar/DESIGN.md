# DESIGN — 선적일 역산 캘린더

## 1. 방향
- 스타일: **관제 데스크.** 짙은 남색 머리말, 선명한 파랑 버튼 하나, 큰 D-day 숫자, 점으로 보이는 상태 표시.
- 이유: 해외영업 담당자는 "선적까지 며칠, 지금 어디가 모자란가"를 숫자와 색으로 먼저 확인한다. 숫자를 크게, 설명은 작게 둔다.
- 레퍼런스에서 가져온 것은 분위기(남색 바탕, 얇고 큰 제목, 굵은 숫자 + 작은 라벨, 점 상태, 채움/윤곽선 버튼 위계)뿐이다. 로고·브랜드명·문구·사진은 쓰지 않는다.

## 2. 글꼴 짝
- 제목: IBM Plex Sans KR (600) · 본문: IBM Plex Sans KR (400, 500)
- 숫자·날짜·작은 라벨: IBM Plex Mono (Plex Mono에 한글이 없으므로 한글 라벨은 Plex Sans KR로 대체)
- 크기: 본문 16px, 큰 숫자 40~48px. 제목은 본문의 1.5배 이상.
- 한글 표시: 둘 다 Google Fonts에서 불러온다. **한글 렌더링은 구현 후 화면으로 확인한다.**

## 3. 색 토큰 (theme-factory 방식: 이름 붙인 팔레트)
| 이름 | 값 | 어디에 |
|---|---|---|
| --color-bg | #F3F5F8 | 배경 |
| --color-surface | #FFFFFF | 카드·표 |
| --color-text | #14202E | 글자 |
| --color-text-sub | #55627A | 보조 글자 |
| --color-line | #DCE1EA | 테두리·구분선 |
| --color-header | #0E2744 | 머리말 바탕 |
| --color-brand | #2F63E8 | 주요 버튼 · 강조 (흰 글자 대비 5.16:1) |
| --color-brand-hover | #1E4FC4 | 주요 버튼 hover (한 단계 어두운 파랑) |
| --color-on-header-border | #FFFFFF | 머리말 위 버튼의 테두리 |
| --color-accent | #0B7F8A | 작은 포인트 (기준일 표시 등) |
| --color-ok / --color-ok-bg | #146C34 / #E3F4EA | 상태: 여유 |
| --color-soon / --color-soon-bg | #9A5A06 / #FDF0D9 | 상태: 임박 (7일 이내) |
| --color-past / --color-past-bg | #55627A / #ECEFF4 | 상태: 기준일 지남 |
| --color-late / --color-late-bg | #C62828 / #FDE8E8 | 상태: 일정 부족 |

- 상태 글자 대비는 계산해서 모두 4.5:1 이상 (여유 5.7, 임박 4.86, 지남 5.34, 부족 4.79).
- 머리말 위 버튼(파랑 on 남색)의 경계 대비는 2.9:1이라 흰 테두리를 함께 쓴다.
- 상태는 색만으로 알리지 않고 글자(여유·임박·지남·부족)와 함께 쓴다.
- 타임라인 단계는 남색~청록 계열 한 줄기로만 쓰고, 상태 색 네 가지와 겹치지 않게 한다.

## 4. 간격·크기
- 8px 단위: 8 · 16 · 24 · 32 · 48 · 64
- 큰 숫자는 라벨보다 3배 이상, 제목은 본문보다 1.5배 이상.
- 최소 터치 영역 44px.

## 5. 움직임
- 움직이는 것: 페이지를 열 때 머리말 한 번, 타임라인 한 번 펼침, 버튼 누를 때 눌림, 수정 영역 열고 닫기.
- 규칙: transform·opacity만 쓴다. 퇴장은 등장의 75%(등장 250ms면 퇴장 180ms). `prefers-reduced-motion`이면 모두 끈다.
- 입력할 때마다 반복되는 움직임은 넣지 않는다.
- 색은 상태가 바뀔 때 즉시 바뀌고(전환 효과 없음), 움직임은 transform·opacity로만 만든다.
- hover는 1~2px 떠오름, active는 scale(0.97). "단 하나의 행동" 버튼(일정 보기)만 hover에서 2px 떠오르고, 첫 화면에서 흰 테두리 고리가 두 번만 퍼진다.
- 토스트는 등장 250ms, 퇴장 180ms. 수정 영역은 열 때만 250ms 등장하고 닫을 때는 즉시 닫힌다.
- disabled: 날짜가 없으면 복사·.ics 버튼을 비활성(회색, 올려도 반응 없음)으로 둔다.

## 6. 버튼 상태 5가지
| 상태 | 주요 버튼(채움) | 보조 버튼(윤곽선) |
|---|---|---|
| 기본 | --color-brand 바탕, 흰 글자 | 흰 바탕, --color-line 테두리 |
| hover | --color-brand-hover 바탕 | --color-bg 바탕 |
| focus | 3px 밝은 파랑 윤곽선 + 2px 띄움 | 같음 |
| active | scale(0.97) | 같음 |
| disabled | --color-line 바탕, --color-text-sub 글자, 눌러도 반응 없음 | 같음 |

## 7. 하지 않을 것
- 보라·파랑 그라데이션
- 시스템 기본 글꼴
- 똑같은 크기의 카드 나열 (결과 카드를 가장 크게, 나머지는 작게)
- 지어낸 후기·숫자·로고, 가짜 고객 목록
- 업종 예시값을 실제 규정처럼 보이게 하는 표현
- 이모지·장식용 아이콘을 버튼·제목에 넣기 (내가 고름)
- 작은 영문 대문자 라벨을 곳곳에 붙이기 (내가 고름. 라벨은 한글로, 영문은 영어 일정 텍스트에서만)
